# ETF Decision Tool

A lightweight ETF decision dashboard with free market data sources, source checks, scoring, recommendations, and peer comparisons.

## Run locally

```bash
python backend/server.py
```

Open http://127.0.0.1:8877

## Deploy on Render

Render can use `render.yaml` or start command:

```bash
python backend/server.py
```

The app uses Python standard library only.

## Data note

Free market data sources are for decision support only and are not exchange-grade real-time feeds.
